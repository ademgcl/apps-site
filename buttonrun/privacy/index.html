Privacy Policy

Button Run keeps your data local.

Effective date: May 30, 2026

Data Collection

Button Run does not collect personal data from players.

Analytics and Tracking

Button Run does not use third-party analytics SDKs, advertising SDKs, or cross-app tracking.

Accounts

Button Run does not require account creation, cloud login, or sign-in to play rooms, retry runs, or track medals.

Local Save Data

The game stores progression such as best medals and room progress locally on the device so the single-player experience works offline.
